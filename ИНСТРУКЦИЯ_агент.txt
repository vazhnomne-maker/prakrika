ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ АГЕНТА-ПОЭТА
=========================================

Созданный агент автоматически генерирует стихи для песен в стиле Сола Моновой
по выбранной теме из файла "женские_посты_о_проблемах_структурировано.txt"

ДОСТУПНЫЕ СКРИПТЫ:
------------------

1. **агент_поэт.py** - Полнофункциональный интерактивный агент
   - Запуск: python агент_поэт.py
   - Возможности:
     * Просмотр всех тем (1-30)
     * Создание стиха по конкретному номеру
     * Создание стиха по случайной теме
     * Автоматическое сохранение в файл

2. **агент_быстрый.py** - Быстрый агент для командной строки
   - Запуск: python агент_быстрый.py <номер_темы>
   - Пример: python агент_быстрый.py 15
   - Возможности:
     * Быстрое создание стиха по указанному номеру
     * Автоматическое сохранение

3. **создать_стих.bat** - Пакетный файл для Windows
   - Запуск: двойной клик по файлу
   - Возможности:
     * Простой интерфейс для ввода номера темы
     * Автоматический запуск Python

ТРЕБОВАНИЯ:
-----------
- Установленный Python 3.x
- Доступ к файлам в папке D:\Kiro_projekt\ptaktika

ПРИНЦИП РАБОТЫ:
---------------
1. Агент загружает выбранную тему и метафоры из файла
2. Использует техническое задание из файла tz_stih.txt
3. Применяет поэтические приемы из гайда analiz_1.txt
4. Создает стих по структуре: 3 куплета + 1 припев
5. Сохраняет результат в новый файл с timestamp

СТРУКТУРА СОЗДАВАЕМОГО СТИХА:
-----------------------------
- Тема и номер
- Использованные метафоры
- 3 куплета (развитие сюжета)
- 1 припев (эмоциональная кульминация)
- Информация о дате создания

ПРИМЕР ИСПОЛЬЗОВАНИЯ:
--------------------
1. Откройте командную строку в папке D:\Kiro_projekt\ptaktika
2. Выполните: python агент_быстрый.py 7
3. Агент создаст стих по теме №7 и сохранит его в файл

АВТОМАТИЗАЦИЯ:
--------------
Для автоматического создания стихов можно использовать:
- Планировщик заданий Windows
- Скрипты с циклами
- Интеграцию с другими программами

ФАЙЛЫ РЕЗУЛЬТАТОВ:
------------------
Стихи сохраняются в формате: стих_тема<номер>_<дата_время>.txt
Пример: стих_тема15_20260517_143022.txt

ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ:
--------------------------
Агент можно модифицировать для:
- Создания стихов на другие темы
- Генерации музыки к стихам
- Создания видео-клипов
- Интеграции с нейросетями

ПОДДЕРЖКА:
----------
Агент создан на основе:
- Технического задания: tz_stih.txt
- Поэтического гайда: analiz_1.txt
- Базы тем и метафор: женские_посты_о_проблемах_структурировано.txt

Для работы требуется корректность этих файлов.
